# Normal Collection release review

The commissioned six-Collection migration preserves stable `release/vX.Y.Z`
pull requests to Main. Previously the common classifier rejected that existing
path because only Develop promotions and separately proven Security releases
were admitted to Main.

The Source-owned normal release classifier recognizes only the six fixed
Collection repository names and numeric IDs. Both PR repositories must match;
the author must be the exact existing Release App login, numeric ID and Bot
type. The branch must contain one canonical stable numeric version. Forks,
foreign identities, arbitrary Main branches and prerelease spellings are not
admitted through this route.

Recognition supplies no successful review or publication evidence. The existing
protected Codex path reviews the complete exact-current candidate with its
existing request, budget, receipt and stale-input guards. Normal Main approval
uses the existing credential-free self-reviewable Environment and genuine
native approval history. Final control revalidates the current tuple, actual
review, product quality, conversations and approval before retaining its native
proof. A skipped approval job without an authenticated prior approval fails.

The normal approval job now follows the protected classifier's approval-needed
output. Both ordinary Develop promotions and these normal Collection releases
use it. Other feature PRs gain no Main route or approval authority. Security's
separately authenticated route keeps its existing contract. Develop promotions
continue aggregating accepted ingress without a second cumulative review.

This code does not install a policy, select its own Source, activate a ruleset,
request an additional review, merge a PR or publish a Collection. The selected
immutable Source must first pass its own normal native review and Main approval,
then each Collection's protected Management evaluation and actual qualification.
Disabled legacy callers must be replaced together with their canonical sources
once the functional replacement is installed. Product checks and the existing
Galaxy import, public readback and exact-version installation remain mandatory.

Task profile: owner-commissioned six-Collection review migration and subsequent
Foundational Galaxy delivery; high risk because Main route authorization changes.
Use the existing session capability and pinned deterministic tests; stop on an
unknown identity, failed gate, source drift or exhausted native review budget.
